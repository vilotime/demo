# 目录与文件规范

左侧目录树完全由 `md/` 的真实结构决定，因此「怎么放文件」就是「目录长什么样」。

## 排序规则

1. **文件夹排在文件前面**，和 Windows 资源管理器一致；
2. 同一层内用自然排序（`Intl.Collator`，开启 `numeric`）：`2-xxx` < `10-xxx`，中文按拼音；
3. 想精确控制顺序时，用零填充的数字前缀最省心：`01-`、`02-`、`03-`。

## 显示名从哪里来

文档里**只写正文**就够了，不需要任何元信息。目录树里每一行的显示文字，取的是正文里的**第一个一级标题**，取不到才退回文件名：

| 文件 | 第一个一级标题 | 目录里显示 |
| --- | --- | --- |
| `md/指南/01-快速开始.md` | `# 快速开始` | 快速开始 |
| `md/notes/meeting.md` | （没有标题） | meeting |

所以「文档标题」这件事，写成正文的第一行 `# xxx` 即可，其余内容从第二行开始。

## 会被忽略的东西

- 以 `.` 开头的文件和文件夹（`.obsidian`、`.DS_Store` 等）；
- `node_modules`、`.git`、`.github` 等构建产物或元数据目录；
- 非 `.md` / `.markdown` 后缀的文件；
- 处理完之后**一个 markdown 文件都没有的文件夹**，不会在目录树里留下空壳。

## 资源文件怎么放

图片、PDF 等附件建议就近放在文档旁边：

```text
md/示例/
├── 01-演示模式示例.md
└── 附件/
    └── 架构图.svg
```

然后在文档里写相对路径即可：

```markdown
![架构图](./附件/架构图.svg)
```

渲染时站点会以**当前文档所在目录**为基准解析相对路径，`../` 也能正确回退。

## 文档之间的链接

链接到另一个 markdown 文件时，站点会拦截点击并在当前页面内跳转（不刷新、不跳走）：

```markdown
[上一篇：快速开始](./01-快速开始.md)
[回首页](../index.md)
[链接到中文文件名](%E5%BF%AB%E9%80%9F%E5%BC%80%E5%A7%8B.md)   ← 包含中文时请用 URL 编码
```

> 小提示：链接里含空格或中文时，写成 `%E5%BC%80...` 这种编码形式最稳妥；
> 站点对两种写法都做了兼容，但编码后的写法在任何环境都不会出问题。
