# 欢迎使用 MD Pages

这是一个**纯静态**的 Markdown 文档站点。所有内容都放在仓库根目录的 `md/` 文件夹里，左侧目录会像文件资源管理器一样，按文件夹层级把它们列出来。

> 你只需要继续往 `md/` 里新建文件夹和 `.md` 文件，然后推送到 GitHub——Actions 会自动生成目录索引并发布，本地不需要任何构建步骤。

## 两种浏览模式

| 模式 | 适合场景 | 怎么进入 |
| --- | --- | --- |
| 阅读模式 | 正常阅读长文档，左侧目录 + 右侧大纲 | 默认模式 |
| 演示模式 | 把文档当成幻灯片讲给别人听 | 右上角点击「演示」，或按 `Ctrl/⌘ + Enter` |

演示模式会按下面的规则把一篇文档切成若干页：

1. 正文里的第一个一级标题（`# 标题`）就是封面页，不需要额外的元信息；
2. 独立成行的分隔线 `---`、`***`、`___` 或 `<!-- slide -->` 注释会被当作分页符；
3. 如果全文没有分页符，则自动按 `##` 二级标题分页（没有二级标题时按 `#` 一级标题）；
4. 单页内容太多放不下时，会自动在段落/列表/代码块之间再次切分，不会溢出画面。

## 站点能力一览

- [x] 目录树按文件夹层级展示，支持折叠、搜索过滤
- [x] 文档内大纲（TOC），滚动时自动高亮当前章节
- [x] GFM 表格、任务列表、删除线、代码高亮
- [x] 深色 / 浅色主题，跟随系统并可手动切换
- [x] 链接可直接分享（地址栏带 `#/md/...`，刷新不丢失）
- [x] 图片路径相对于当前文档解析，`./图.svg` 这样写就行
- [ ] 数学公式（暂未启用）
