# 演示模式示例

这一页是用来演示**幻灯片模式**的。点击右上角「演示」按钮（或按 `Ctrl/⌘ + Enter`）即可进入。

---

## 分页规则

一篇普通文档，用独立成行的 `---` 就能切开：

```markdown
# 第一页标题

正文……

---

## 第二页

正文……
```

除此之外还支持 `***`、`___` 以及显式注释 `<!-- slide -->`。

***

## 自动分页

如果一页装不下，演示模式会**自动**在段落、列表项、代码块之间找到合适的位置，把内容顺延到下一页，而不是让它溢出到屏幕外面。

- 这条列表比较长，用来触发自动切分
- 演示模式下每一页都会保持 16:9 的固定画布比例
- 再长的文档也不会出现滚动条
- 你完全不用手动控制每一页放多少字

---

## 键盘操作

| 按键 | 作用 |
| --- | --- |
| `→` `↓` `Space` `PageDown` | 下一页 |
| `←` `↑` `PageUp` | 上一页 |
| `Home` / `End` | 第一页 / 最后一页 |
| `o` / `Esc` | 幻灯片总览 |
| `f` | 进入 / 退出全屏 |
| `q` | 退出演示，回到阅读模式 |

触屏设备上也可以左右滑动翻页。

---

## 排版建议

> 一页只讲一件事。
>
> 每页 3~5 个要点、一张图，观众才跟得上。

- 标题尽量短，用 `##` 作为每页的标题层级
- 大段正文改写成要点列表
- 代码块只保留关键几行
- 结论单独放一页

---

## 结束页

演示模式同样支持深链接：地址栏会记录当前页码，刷新后仍停在这一页。
